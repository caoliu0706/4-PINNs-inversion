# 4-PINNs-inversion
本代码是关于利用物理信息神经网络（PINNs）反演对流换热系数。
（1）“PINN_hard_inverse_fixed_h.py”文件：利用PINNs反演得到固定的对流换热系数
（2）“PINN_hard_inverse_unfixed_h.py”文件：利用PINNs反演得到随温变化的对流换热系数
（3）“data.txt”文件：计算代码所需要的测温数据
（4）“2026 基于物理信息神经网络反演热加工过程界面传热系数.pdf”文件：已发表的学术论文
文献引用格式：曹流, 魏如威, 张沁丹. 基于物理信息神经网络反演热加工过程界面传热系数[J]. 特种铸造及有色合金, 2026, DOI:10.15980/j.tzzz.T20250455

This code is about using physics-informed neural networks (PINNs) to invert the convective heat transfer coefficient.
(1) "PINN_hard_inverse_fixed_h.py" file: Uses PINNs to invert and obtain a fixed convective heat transfer coefficient.
(2) "PINN_hard_inverse_unfixed_h.py" file: Uses PINNs to invert and obtain a temperature-dependent convective heat transfer coefficient.
(3) "data.txt" file: The temperature measurement data required by the computation code.
(4) "2026 基于物理信息神经网络反演热加工过程界面传热系数.pdf" file: A published academic paper.
Literature citation format: 曹流, 魏如威, 张沁丹. 基于物理信息神经网络反演热加工过程界面传热系数[J]. 特种铸造及有色合金, 2026, DOI:10.15980/j.tzzz.T20250455
